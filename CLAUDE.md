# AccountaBall

AccountaBall — a macOS floating widget that watches your screen every ~5s to keep you accountable to the task you declared.

> **Windows port in progress (see `windows/`).** A native C#/.NET + WinUI 3 port
> at full parity is underway. Design:
> `planning/plans/2026-06-10-windows-port-design.md`. Plan + live build progress
> (what's done / what's next): `planning/plans/2026-06-10-windows-port-implementation.md`
> — **read its "BUILD PROGRESS" section before continuing the port.** The macOS
> Swift source (`src/`) is a separate repo (`jecohub/AccountaBall-macOS`) and is
> the spec for the remaining `AccountaBall.Core` ports.

## Tech Stack
- Frontend: SwiftUI + NSPanel (floating, always-on-top, borderless)
- Backend: N/A (fully local)
- Database: UserDefaults (declared tasks) + SwiftData (v3: WorkSession,
  TimelineEntry, JustificationEvent, KnowledgeTask, Allowance, TaskCompletion)
- Deploy: macOS .app bundle (notarized, macOS 14+ / Sonoma required)
- AI: Ollama (default, local) → OpenRouter (optional cloud) — selected via
  the `AI_PROVIDER` env var. Claude is a legacy/secondary path.
- Capture: ScreenCaptureKit (requires Screen Recording permission)
- OCR: Vision.framework (offline, no third-party dependency)

## AI Provider (env-driven)
- `AI_PROVIDER` — `ollama` (default) or `openrouter`.
- Ollama: `OLLAMA_HOST` (default `http://localhost:11434`),
  `OLLAMA_MODEL` (default `qwen2.5:7b`). Requires Ollama running + model pulled.
- OpenRouter: `OPENROUTER_API_KEY` (required), `OPENROUTER_MODEL`
  (default `anthropic/claude-haiku-4-5`).
- No auto-fallback: a misconfigured provider sets `state.setupHint` and the
  app launches on local Ollama so the hint is visible.

## Naming Conventions
- Swift types/structs/classes: PascalCase (e.g. `AccountaBallPanel`, `TaskSession`)
- Properties/methods: camelCase (e.g. `currentTask`, `startCapture()`)
- Files: match the primary type they define (e.g. `AccountaBallPanel.swift`)
- Specs: feature-name_spec.md
- Decision records: YYYY-MM-DD-decision-title.md

## Key Constraints
- macOS 14+ (Sonoma) required — SwiftData minimum (also covers ScreenCaptureKit)
- Screen Recording permission: one-time prompt, stored in System Settings
- Notifications permission: required for off-task nudges
- Ball visual: smiling face, different expressions per state (on-task / off-task / done)
- SwiftData store lives in the app's default Application Support container;
  debug log at `~/Library/Application Support/AccountaBall/logs/accountaball.log`
